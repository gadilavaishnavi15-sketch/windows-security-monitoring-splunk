# Windows Security Monitoring & Failed-Login Detection Using Splunk

## Project Overview

A hands-on cybersecurity project focused on Windows security monitoring and failed-login detection using Splunk.

The project demonstrates how Windows security logs can be collected, analyzed, monitored, and used to create security alerts in a SOC environment.

## Tools Used

- Splunk Enterprise
- Splunk Universal Forwarder
- Windows Security Event Logs
- Ubuntu
- SPL

## Project Work

- Windows log collection
- Security event analysis
- Failed-login investigation
- Detection rule creation
- Splunk alert configuration
- Security monitoring dashboard
